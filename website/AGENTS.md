# Website Agent Guide

Work only inside `website/`. Do not edit the extension implementation, root package files, syntaxes, snippets, language configuration, or root README.

Before editing docs, read the relevant guidance file under `website/_agent/skills/`.

- Preserve the distinction between stable V1 features and planned Workbench V2 features.
- Mark released extension behavior with stable wording.
- Mark roadmap or design-direction material with planned or preview wording.
- Keep documentation original. Do not copy official GNU Bison, Flex, RE-flex, VS Code, or Docusaurus manuals into this site.
- Use official references as links, not as mirrored manuals.
- Prefer small, focused pages over long omnibus pages.
- Keep examples minimal and testable where possible.
- Write clear developer-facing English.
- Do not touch extension source code from website tasks.
