# Bison/Flex Language Support Website

This directory contains the Docusaurus documentation website for Bison/Flex Language Support and the planned Bison/Flex Workbench V2.

## Development

```bash
npm install
npm run start
```

## Build

```bash
npm run build
```

All website work should stay inside `website/`. Product documentation should keep stable V1 extension behavior separate from planned Workbench V2 behavior.
