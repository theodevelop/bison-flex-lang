# UI and UX Docs Site Guidance

- The homepage should make the product name, VS Code context, and Bison/Flex/RE-flex scope obvious in the first viewport.
- Keep the hierarchy direct: hero, stable features, V2 preview, learning paths.
- Use feature cards for scannable entry points, but avoid stacking cards inside cards.
- Make stable and preview states clear with visible labels and explanatory copy, not color alone.
- Navigation should stay shallow and predictable on desktop and mobile.
- Use accessible contrast and avoid relying on thin color differences.
- Keep the visual system restrained: one accent color, neutral surfaces, and a technical workbench feeling.
- Avoid excessive animation, decorative gradients, and visual effects that distract from documentation.
